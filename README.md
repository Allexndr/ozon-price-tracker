# Ozon Telegram Bot

Телеграм-бот для отслеживания товаров на Ozon с функциями фильтрации и уведомлениями об изменении цен.

## Описание

Этот бот позволяет пользователям отслеживать товары на Ozon по различным критериям и получать уведомления о снижении цен. 
Основные возможности:

- Поиск товаров по ссылкам, ключевым словам или фото
- Фильтрация результатов с помощью стоп-слов
- Отслеживание изменения цен
- Автоматические уведомления при снижении цены

## Установка и настройка

### Предварительные требования

- Python 3.10 или выше
- pip (менеджер пакетов Python)
- Chrome/Chromium браузер

### Установка

1. Клонирование репозитория:
```bash
git clone https://github.com/yourusername/ozon-telegram-bot.git
cd ozon-telegram-bot
```

2. Установка зависимостей:
```bash
pip install -r requirements.txt
```

3. Создание и настройка .env файла на основе шаблона .env.example:
```bash
cp .env.example .env
```

4. Отредактируйте .env файл, добавив необходимые настройки:
```
# Токен Telegram-бота, полученный от @BotFather
TELEGRAM_BOT_TOKEN=your_bot_token_here

# Настройки парсера
HEADLESS_MODE=True  # Запускать браузер в фоновом режиме (True/False)
CHROME_EXECUTABLE_PATH=  # Путь к исполняемому файлу Chrome (если нужно)
PRICE_TOLERANCE_PERCENT=20  # Допустимое отклонение цены в процентах
```

### Запуск бота

```bash
python run.py
```

## Обработка CAPTCHA

Бот использует `undetected_chromedriver` для работы с Ozon и автоматического обхода базовых механизмов защиты от ботов. Эта библиотека эмулирует поведение настоящего браузера, что позволяет обходить большинство простых проверок на ботов без использования платных сервисов.

## Используемые технологии

- [aiogram](https://github.com/aiogram/aiogram) - фреймворк для Telegram Bot API
- [selenium](https://selenium-python.readthedocs.io/) - для автоматизации браузера
- [undetected-chromedriver](https://github.com/ultrafunkamsterdam/undetected-chromedriver) - для обхода обнаружения ботов
- [python-dotenv](https://github.com/theskumar/python-dotenv) - для работы с переменными окружения
- [loguru](https://github.com/Delgan/loguru) - для логирования

## Команды бота

- `/start` - Начать работу с ботом
- `/help` - Показать справку по командам
- `/add` - Добавить товар для отслеживания
- `/list` - Показать список отслеживаемых товаров
- `/delete` - Удалить товар из отслеживаемых
- `/reset` - Сбросить историю поиска и текущую сессию
- `/daily` - Показать ежедневное стоп-слово
- `/stat` - Показать статистику по товарам
