# Ozon Price Tracker Bot

Telegram бот для отслеживания цен на товары Ozon.

## Возможности

- Отслеживание цен на товары по артикулам
- Поддержка различных форматов ввода товаров
- Фильтрация по стоп-словам и продавцам
- Ежедневное стоп-слово
- Кеширование результатов поиска
- Статистика запросов

## Запуск с использованием Docker (рекомендуется)

1. Клонируйте репозиторий:
```bash
git clone https://github.com/Allexndr/Ozon_parser.git
cd Ozon_parser
```

2. Создайте файл `.env` на основе `.env.example`:
```bash
cp .env.example .env
```

3. Отредактируйте файл `.env`, указав необходимые значения.

4. Запустите бота с использованием Docker Compose:
```bash
docker-compose up -d
```

5. Просмотр логов:
```bash
docker-compose logs -f
```

6. Остановка бота:
```bash
docker-compose down
```

## Установка без Docker

1. Клонируйте репозиторий:
```bash
git clone https://github.com/Allexndr/Ozon_parser.git
cd Ozon_parser
```

2. Создайте виртуальное окружение и установите зависимости:
```bash
python -m venv venv
source venv/bin/activate  # для Linux/Mac
# или
venv\Scripts\activate  # для Windows
pip install -r requirements.txt
```

3. Создайте файл `.env` на основе `.env.example`:
```bash
cp .env.example .env
```

4. Отредактируйте файл `.env`, указав необходимые значения.

5. Запуск:
```bash
python run.py
```

## Использование

1. Отправьте команду `/start` боту
2. Используйте `/help` для получения списка доступных команд
3. Создайте новый список товаров командой `/new`
4. Добавьте товары в одном из поддерживаемых форматов
5. Используйте `/done` для завершения ввода и начала поиска

## Форматы ввода товаров

1. Простой формат:
```
название_товара артикул,цена[,валюта]
```

2. Структурированный формат:
```
ТОВАР 1
ИМЯ: название
АРТИКУЛ: артикул
ЦЕНА: цена
[ВАЛЮТА: валюта]
```
