# Ozon Price Tracker Bot

Telegram бот для отслеживания цен на товары Ozon.

## Возможности

- Отслеживание цен на товары по артикулам
- Поддержка различных форматов ввода товаров
- Фильтрация по стоп-словам и продавцам
- Ежедневное стоп-слово
- Кеширование результатов поиска
- Статистика запросов

## Установка

1. Клонируйте репозиторий:
```bash
git clone https://github.com/yourusername/ozon-price-tracker.git
cd ozon-price-tracker
```

2. Создайте виртуальное окружение и установите зависимости:
```bash
python -m venv venv
source venv/bin/activate  # для Linux/Mac
# или
venv\Scripts\activate  # для Windows
pip install -r requirements.txt
```

3. Создайте файл `.env` на основе `.env.example`:
```bash
cp .env.example .env
```

4. Отредактируйте файл `.env`, указав необходимые значения:
- `TELEGRAM_BOT_TOKEN` - токен вашего Telegram бота
- `ADMIN_TELEGRAM_ID` - ваш Telegram ID для административных функций
- `CAPTCHA_API_KEY` - ключ API сервиса капчи
- Остальные настройки по необходимости

## Запуск

```bash
python run.py
```

## Использование

1. Отправьте команду `/start` боту
2. Используйте `/help` для получения списка доступных команд
3. Создайте новый список товаров командой `/new`
4. Добавьте товары в одном из поддерживаемых форматов
5. Используйте `/done` для завершения ввода и начала поиска

## Форматы ввода товаров

1. Простой формат:
```
название_товара артикул,цена[,валюта]
```

2. Структурированный формат:
```
ТОВАР 1
ИМЯ: название
АРТИКУЛ: артикул
ЦЕНА: цена
[ВАЛЮТА: валюта]
```
