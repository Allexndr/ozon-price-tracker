# ИНСТРУКЦИЯ ПО ИСПОЛЬЗОВАНИЮ БОТА

## Команды

- `/start` – запуск бота
- `/help` – список команд
- `/article 12345678` – поиск по артикулу
- `/article 12345678 1000` – поиск с проверкой цены
- `/filters` – показать фильтры
- `/stopword add слово` – добавить стоп-слово
- `/stopword remove слово` – удалить стоп-слово
- `/blacklist add продавец` – добавить в черный список
- `/blacklist remove продавец` – удалить из черного списка
- `/dailyword` – показать текущее стоп-слово
- `/reset` – сбросить состояние бота
- `/stats` – статистика запросов
- `/new` – создать новый список товаров

## Форматы списка товаров

1. **Через сообщение**, введите:
   ```
   Название товара артикул,цена
   Название товара2 артикул2,цена2
   ```

2. **Через файл .txt** с текстом в формате:
   ```
   Название товара артикул,цена
   Название товара2 артикул2,цена2
   ```

3. **Структурированный формат**:
   ```
   ТОВАР 1
   ИМЯ: название
   АРТИКУЛ: 12345678
   ЦЕНА: 1000
   ```

## Фильтрация

1. **Стоп-слова**: товары с этими словами не показываются
   - `/stopword add доставка` – добавить стоп-слово
   - `/stopword` – показать список

2. **Черный список**: товары от этих продавцов не показываются 
   - `/blacklist add ООО Продавец` – добавить продавца
   - `/blacklist` – показать список

## Решение проблем

- Если команды не работают, используйте `/reset`
- Если бот не отвечает, перезапустите его
- При ошибках проверьте формат ввода данных

## Технические требования

- Telegram
- Интернет-соединение
- У администратора: Python 3.7+, aiogram 3.x

## Установка и запуск (для администратора)

1. Создайте файл `.env` с переменными:
   ```
   TELEGRAM_BOT_TOKEN=ваш_токен
   ADMIN_TELEGRAM_ID=ваш_id
   ```

2. Запустите:
   ```
   python3 run.py
   ```
